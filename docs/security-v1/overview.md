# ModelDB 安全 V1 功能简介

更新日期：2026-10-23。面向实例所有者、运维人员和接入应用开发者。实际阶段状态以[里程碑台账](../security-v1-milestones.md)和[SEC-M6 交付记录](../security-v1-deliveries/SEC-M6.md)为准。

ModelDB 安全 V1 将“访问数据库的凭据”和“保护磁盘数据的密钥”分开管理。管理员可以给应用分配具体库、模型或发布接口的权限，及时撤销访问，查看审计记录，并在受控流程中备份、恢复或迁移数据库。更换网络 Token 不需要重加密数据库。

## 可以做什么

| 能力         | 用户可执行的操作                                            | 当前边界                                                                     |
| ------------ | ----------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 数据加密     | 创建、打开和保存使用独立随机密钥的 Vault                    | Windows DPAPI 与账号 ACL 保护本机密钥；旧 Vault 不自动转换                   |
| 身份与授权   | 创建应用身份、限权凭据，设置有效期、轮换和撤销              | 管理员身份不自动获得业务数据权限                                             |
| 浏览器连接   | 用一次性邀请配对 Designer、Data Studio 或 Web               | 短期 HttpOnly 会话；页面不保存长期 Token；远程使用 HTTPS/WSS                 |
| 应用接口     | 通过 SDK、HTTP 或 Postman 调用已授权的发布接口              | 发布版本摘要受限；不能据此访问其他模型或通用管理接口                         |
| 安全中心     | 查看凭据、设备/会话、权限、密钥状态和审计                   | 安全管理会话由受保护本机入口签发                                             |
| 防护维护     | 管理双入口网络名单、限流、临时封禁，预览、确认或回滚规则    | 误锁可通过本机 CLI 修复；历史密钥不会自动销毁                                |
| 单库备份     | 创建、列表验证、下载、上传和恢复加密备份                    | 一个包包含一个 Vault；自动备份默认关闭                                       |
| 完整受信迁移 | 使用接收方公钥导出，在目标实例重新加密后显式恢复为新库      | 离线 CLI；接收方必须可信，私钥和口令由接收方保管                             |
| 独立恢复材料 | 导出/校验密钥快照、检查历史 Vault 依赖，恢复到全新安全目录  | 本地实现及隔离测试已具备；独立 Windows 设备/OS 身份实测仍待验收              |
| 模型资产交付 | 选择模型、Designer 接口依赖和元数据，签名加密后预览导入新库 | 离线 CLI；v1 为模型包，v2 增加 Designer 依赖和双库分阶段发布；接口导入后禁用 |

## 备份、灾备与资产分享的区别

日常备份保存完整的单库内容并加密。仅持有备份文件，不能在丢失原密钥后恢复；还需要覆盖该库历史密钥的独立恢复材料及其口令。新增库或轮换数据密钥后，应重新生成恢复材料。

完整受信迁移适用于自己控制或明确受信任的接收者。源端按接收方公钥加密，接收端用自己的密钥重新保护，导入先生成已验证的本地备份，再由操作者选择恢复。目标实例的凭据、网络策略和审计历史保持独立。

S6.3 首批模型资产包已提供独立加密、发布者签名、指纹信任确认、冲突预览和新业务库导入。每包生成新的 PEK，正文只含所选模型、父模型依赖、选中范围内关系和可选数据，不含源 Vault 或源 DEK；数据中的完整 I18N 字典保持不变。签名说明对应私钥签署了内容，接收者仍须通过可信渠道核对发布者公钥指纹。

v2 包增加所选 Query/Operation Interface、Binding Surface、固定版本依赖以及模型/字段/关系显示名、基础坐标和布局；导入时映射 Designer 实体身份与库归属。接口访问策略移除，目标端默认禁用，需要重新审核和发布授权。双库发布中断时，普通服务拒绝启动，OS 所有者可用原包离线预览后续跑；加密任务归档保留发布前 Designer 快照。

选择以完整模型为单位，不支持逐字段或逐行裁剪。v2 不搬运整个 Designer 库、画布快照、图层、调用日志或源访问策略；不支持无版本接口依赖和不明关系引用，遇到这些内容会拒绝导出。完整迁移包则携带源 DEK 的加密内容，仅适合完整受信迁移。

## 交付内容

独立安全台账存储主体、凭据摘要、授权、会话摘要、策略版本、访问代次和公开密钥引用，使用真实 Windows CurrentUser DPAPI 保护。状态与对应早期管理审计采用同一恢复提交；不依赖业务 Vault 或 Designer 系统模型。实例初始化有进程独占锁和完成标记，缺失/损坏材料拒绝重建为空台账。

本机管理使用具备 owner/SYSTEM DACL 的 Named Pipe，OS impersonation 核验调用者 SID，拒绝远程客户端和管道名称抢占，无普通 loopback HTTP 管理员回退。CLI 支持状态、主体创建、凭据创建/列表/轮换/撤销及带 `--yes` 的访问重置。新凭据默认无数据权限，原文仅交付到新建的受 ACL 保护文件。

新安装默认生成无共享 Token 的 `security: { version: 1 }` 配置。当前 registry 模式除健康检查和预检外，业务/管理 HTTP 和 WS 均通过临时门禁明确返回 503；不会把新限权凭据传入旧全局 Token 通道当作全权限使用。完整网络授权在 SEC-M3，Designer 安全配对在 SEC-M4。

使用方法、目录格式、CLI 命令和失败语义见[实例身份与凭据契约](../security-v1-identity-contract.md)。

## 限制和后续验收

- M2 不提供完整网络授权、浏览器配对、安全中心或新 SDK 协议。registry 模式当前的 503 是阶段门禁，不是最终用户体验，也不能通过跳过验证来解除。
- Windows CurrentUser DPAPI 与当前受信账号/SYSTEM 为本阶段支持边界；系统身份完全失陷、文件被整体回滚或删除不在本机台账能够独立抵御的范围内。
- 早期管理审计在加密台账内，默认上限 10,000；满时拒绝敏感变更。独立 `audit/`、轮转、保留、分页检索和网络失败/IP 统计在 SEC-M5。被内核 ACL 提前拒绝的连接不冒充已经进入应用日志的事件。
- 台账管理写入采用全量序列化与 DPAPI 子进程，适用于本阶段低频管理操作；未进行大规模容量/性能验收。存储、消息与记录数量均有界，超限拒绝，不覆盖历史。凭据 CLI 有 offset/limit 分页，过大的元数据页返回固定错误，不终止维护进程。
- 测试包含受控时钟、模拟保护写入失败和真实进程退出，未执行物理磁盘耗尽、硬件断电或真实远程 SMB 演练。远程拒绝通过内核创建标志实施，未以本机 ACL 测试冒称已完成跨机器验收。
- Token 交付失败时服务端可能已经提交，应查询元数据并撤销交付不明的凭据；不返回原文，不自动重发。独立恢复、主密钥轮换和迁移仍待 SEC-M5/M6。
- 原配置中的共享 Token 及旧协议仅保留为未自动切换的 legacy 开发路径，未声称全仓已移除长期明文凭据。

## 当前 Designer 故障及环境影响

对现有 9091 服务的只读检查显示：`/health` 与带当前配置 Token 的管理状态均为 200；读取 `model_designer_workspace` catalog 返回 500 / `VAULT_LEGACY_FORMAT`，对应 Vault 仍为 `MDB4SVLT`。失败在验证之后的开库阶段；新引擎要求 `MDB5SVLT`。

后续 M3/M4 会接入新的网络授权和 Designer 会话，但不会自动转换这个旧库。旧数据需单独按切换方案保留、重建或迁移；本次保留原文件和当前配置，没有重启/切换 9091、重置真实访问凭据、删除旧库或修改默认安装目录的安全材料。工作区构建产物已更新，未推送 Git 或发布 npm。

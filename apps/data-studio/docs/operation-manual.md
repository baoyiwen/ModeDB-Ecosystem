# Data Studio 操作手册

## 1. 使用前准备

需要先确认：

- `@mode-db/server` 已启动
- 已知 `host / port / connectToken`
- 至少存在一个可用逻辑库

## 2. 启动方式

在仓库根目录执行：

```bash
pnpm --filter data-studio dev
```

打开 Vite 地址后会先进入连接页。

## 3. 连接流程

### 3.1 输入连接参数

填写：

- host
- port
- token

点击连接后，前端会先调用 `listDatabases` 列出逻辑库。

### 3.2 打开逻辑库

从下拉中选择目标逻辑库后点击打开，系统会：

1. 建立远程客户端连接
2. 读取 catalog
3. 进入工作区

## 4. 工作区常见操作

### 4.1 切换模型

顶部模型下拉用于切换当前模型；切换后：

- 表格查询快照会重建
- 透视维度会重置
- 导入面板目标模型会变化

### 4.2 切换视图

可切换：

- 表格
- 透视
- 导入

如果当前存在未提交修改，切换会被阻止并给出提示。

### 4.3 编辑并提交

在表格类视图中修改后，改动会先进入 staging。

点击工具栏提交后，系统会：

1. 将 staged operation 聚合
2. 通过 `applyAll` 提交到 engine
3. 刷新查询结果
4. 给出成功 / 失败提示

### 4.4 导入数据

导入页支持：

- 字段映射
- 类型转换
- 清洗规则
- 关系绑定辅助

提交导入后会显示写入结果、失败条数与必要提示。

## 5. 常见问题

### 5.1 连不上服务

检查：

- token 是否正确
- server 是否启动
- 端口是否一致

### 5.2 没有模型可选

可能原因：

- 目标逻辑库 catalog 为空
- 管理面 catalog 读取失败

### 5.3 视图切换被拦截

通常说明当前存在未提交编辑；先提交或回退再切换。

## 6. 推荐使用习惯

- 连接成功后先确认模型列表是否符合预期
- 批量修改优先在一个视图内完成后再提交
- 导入前先确认目标模型字段与字段类型

# Model Designer 操作手册

本文面向产品、测试、实施、非核心开发和首次接手该模块的同学，重点描述“如何连接、如何打开、如何编辑、如何保存、如何排查”。

## 1. 进入模块前需要准备什么

你需要确认以下信息：

- `host`
- `port`
- `connect token`
- 目标业务库名称

还需要确认：

- ModeDB Server 已经启动
- 设计器专属库允许自动创建
- 目标业务库已经存在，或者准备通过连接页创建

## 2. 启动方式

在仓库根目录执行：

```bash
pnpm --filter model-designer dev
```

浏览器打开 Vite 提供的地址后，会先看到连接页。

## 3. 连接流程

### 3.1 填写连接参数

在连接页输入：

- 主机地址
- 端口
- token

可选：

- 勾选“记住 Token”

注意：

- “记住 Token”用于预填表单
- 刷新后自动重连依赖的是 session token，不完全等价于“记住 Token”

### 3.2 列出并选择业务库

点击“列出逻辑库并继续”后，系统会：

1. 调用 `listDatabases`
2. 确保设计器专属库存在
3. 初始化设计器 catalog
4. 拉取逻辑库列表

此时你可以：

- 选择已有业务库
- 创建新业务库
- 编辑逻辑库展示名称与描述

## 4. 进入画布后能做什么

### 4.1 左侧工具栏

- 选择模式
- 新增模型模式
- 删除模式
- 连线模式

部分按钮当前仍是占位或只读态，例如：

- 编辑
- 多选
- 平移
- 缩放
- 撤销
- 重做

### 4.2 底部工具栏

- 保存：将当前设计器图与业务库 catalog 对齐后，推送到设计器专属库
- 拉取：从业务库重新读取 catalog 并刷新画布
- 力导布局
- 网格
- 吸附辅助

### 4.3 右侧侧栏

根据当前状态显示：

- 模型信息
- 字段列表
- 关系详情
- 图层结构
- 通知中心
- 设置面板

## 5. 常见操作

### 5.1 新建模型

1. 点击左侧“新增模型”
2. 在画布空白处点击或双击
3. 选中新模型后，在右侧补充：
   - 唯一名
   - 展示名
   - 描述
   - 颜色
   - 所属页面

### 5.2 新建关系

1. 切换到连线模式
2. 从源模型发起连线
3. 连接到目标模型
4. 在右侧关系详情中补充名称、描述和方向信息

### 5.3 编辑字段

在模型被选中时，字段面板中可编辑：

- 字段名
- 字段类型
- 是否必填
- 展示名
- 字段描述

常见动作：

- 单行快速编辑基础字段信息
- 点击详情图标展开高级信息
- 新增字段
- 删除字段
- 拖拽调整字段顺序

### 5.4 保存设计

点击底部“保存”后，系统会：

1. 读取当前业务库 catalog
2. 将 catalog 导入设计器专属库
3. 生成 `MldgDocument`
4. 推送 `sys_designer_graph` 快照

保存成功后，通知区会有相应提示。

### 5.5 拉取设计

点击底部“拉取”后，系统会：

1. 读取业务库 catalog
2. 导入设计器专属库中的模型/关系目录
3. 重新加载画布

如果本地画布有未保存修改，拉取后的结果会覆盖当前可视状态。

## 6. 数据清理

### 6.1 清空单模型数据

在模型信息面板底部可执行：

- 清空该模型对应的业务数据

注意：

- 只清业务行数据
- 不删模型定义
- 不删关系定义

### 6.2 清空整库数据

在设置面板中可执行：

- 清空当前逻辑库中的全部行数据

注意：

- 只清数据
- schema 仍保留

## 7. 常见问题

### 7.1 连不上服务

优先检查：

- host 是否正确
- port 是否正确
- token 是否正确
- 服务端是否启动

### 7.2 打开后没有模型

可能原因：

- 业务库本身为空
- catalog 拉取失败
- 设计器专属库初始化失败

建议先看浏览器控制台和通知中心。

### 7.3 保存后刷新丢失

重点检查：

- 是否真的点击过保存
- 保存时是否报错
- `sys_designer_graph` 是否成功写入
- 是否在刷新前执行了拉取覆盖本地状态

### 7.4 字段或关系显示不完整

可能原因：

- 业务库 catalog 当前只返回了简化字段目录
- 某些字段细节还未在 server catalog 接口中暴露
- 设计器侧历史数据与当前导入逻辑不完全对齐

## 8. 推荐操作习惯

- 每次大改前先拉取一次
- 批量调整后及时保存
- 不要把设计器专属库当业务库使用
- 不要直接手改 `sys_*` 行数据，除非你清楚导入与同步链路
